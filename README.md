# X自動投稿づくり（Claude スキル）

毎朝、AIの最新ニュースを調べて投稿案を作り、確認できる時間をはさんでから X（旧Twitter）に自動で投稿する仕組みを、Claude と一緒に組み立てるスキルです。
公立小学校の教員「ビット@AI実践家」が、自分の発信のために作って毎朝使っているものを公開しています。

スキルとは、Claude に「この仕事はこの手順でやってね」と覚えさせる指示書のセットです。入れておけば、「Xに毎朝AIニュースを自動投稿したい」と話しかけるだけで、決まった手順で組み立てを案内してくれます。

## できあがる仕組み

| 時刻（既定） | 起きること | あなたがすること |
|---|---|---|
| 5:00 | クラウドの Claude がAIニュースを調べ、投稿案を1本作って置いておく。画像（発表ページのスクショか、AIで作った図）も付けられる | なし |
| 5:00〜7:00 | 確認の時間 | スマホで投稿案を見て、ダメなら消す（見なくても投稿される） |
| 7:00 | GitHub が投稿案を X に投稿し、記録を残す | なし |

時刻・投稿の型・調べる会社や機関は、組み立てのときに変えられます。

## 始める前に知っておいてほしいこと

**お金がかかります。** X の API（プログラムから投稿するための窓口）は、使った分だけ払う方式です。無料枠はありません。

| 内容 | 1日1本×30日の目安 |
|---|---|
| 文章だけ（画像付き・スクショも同じ） | 約70円 |
| AIで図を作る日がある（fal） | 最大で約450円 |

料金は 2026年10月時点のものです。変わることがあるので、正しい金額は X の開発者サイトの画面で確かめてください。最初に $5 ほどクレジットを買えば、数か月もちます。

**次の登録が要ります。**
1. X の開発者サイト（https://console.x.com）の登録と、クレジットの購入（カードが必要）
2. GitHub のアカウント（無料）
3. Claude の有料プラン（クラウドで決まった時刻に Claude を動かす「routine」を使うため）
4. 画像を AI で作る場合だけ：fal（https://fal.ai）のアカウントと少しのクレジット

**長い投稿について**：投稿の型どおりだと 400〜600 字になります。X Premium に入っていないと 140 字までしか投稿できないので、そのときは組み立ての途中で型を短くしてもらってください。

**お金をかけたくない人へ**：Claude で投稿文を作り、X の予約投稿（投稿画面の時計マーク）で時刻を決める方法なら、手作業は残りますが無料です。

## 入れ方

zip をダウンロードしてください。**zip は解凍せず、そのまま使います。**

- [X自動投稿づくり（x-jidou-toukou.zip）](https://github.com/3Daddy-AI/x-jidou-toukou-skill/releases/latest/download/x-jidou-toukou.zip)

### Claude Code（おすすめ）

zip を解凍し、できたフォルダを `~/.claude/skills/` に置きます。
GitHub への送信や毎朝の予約を Claude が代わりにやってくれるので、手作業がいちばん少なく済みます。

### ブラウザ版・デスクトップアプリの Claude（Chat / Cowork）

1. 設定を開き、スキルの設定画面に進む
2. ダウンロードした zip をアップロードする
3. 新しいチャットで「Xに毎朝AIニュースを自動投稿したい」と話しかける

こちらでも案内はしてくれますが、GitHub の画面での操作（ファイルのアップロード・合言葉の登録など）を自分の手で行う場面が増えます。

※ 画面の名前や、使えるプランは変わることがあります。うまくいかないときは、Claude の公式ヘルプで「スキル」を調べてください。

## 使う前に必ず読んでください

- **AIが書いた投稿案は、できるだけ投稿前に目を通してください。** 確認しなかった日も自動で投稿されます。出したくない日は、投稿案を消せば止まります
- **合言葉（APIキー）は、Claude とのチャットに貼らないでください。** スキルの案内どおり、GitHub の設定画面などに自分で入れてください
- **勤務先の決まりに従ってください。** 仕事用ではなく、個人の発信用のアカウントで使うことをおすすめします
- スクショは「引用」として載せる作りです。文章が主役で、出典を必ず書きます
